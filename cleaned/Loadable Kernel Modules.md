# Loadable Kernel Modules (LKM)

### Concept
Loadable Kernel Modules are object files containing code that can be dynamically loaded into or removed from the Linux kernel at runtime. This allows for a modular kernel that supports a wide range of hardware without requiring all drivers to be built into the core kernel binary.

![LKM Overview and Dynamic Loading](../src/files/019dae79-9d0a-737d-acbd-e4ef4d11ddde/image.png)

### Key Points
- **File Format**: LKMs use the `.ko` (kernel object) extension.
- **Binary Compatibility**:
    - **vermagic**: A metadata string (in `.modinfo`) containing kernel version and config (SMP, preempt) used to ensure compatibility.
    - **Symbol Versioning (`CONFIG_MODVERSIONS`)**: Uses CRC checksums of function prototypes to allow loading modules across different kernel versions if the ABI is stable.
- **Licensing and Visibility**:
    - **`MODULE_LICENSE("GPL")`**: Declares the module's license.
    - **`EXPORT_SYMBOL_GPL`**: Restricts certain kernel symbols to modules with a GPL-compatible license. Non-GPL modules "taint" the kernel.
- **Reference Counting**: The kernel uses `try_module_get()` and `module_put()` to manage a module's usage count, preventing it from being unloaded while in use.
- **Dependency Management**:
    - **`modules.dep.bin`**: A binary index generated by `depmod` for high-performance dependency lookup by `modprobe`.
- **Management**:
    - **Blacklisting**: Files in `/etc/modprobe.d/` can prevent modules from being auto-loaded (`blacklist`) or prevent loading entirely (`install <module> /bin/false`).

### Example
**Listing Loaded Modules:**
```bash
lsmod                         # Lists name, size, and usage count
```

**Checking Module Compatibility (vermagic):**
```bash
modinfo <module_name> | grep vermagic
```

### Notes / Observations
- **Module Reference Count**: If `lsmod` shows a non-zero usage count for a module, `rmmod` will fail to protect the system from crashes.
- **No Standard C Library**: Modules must use kernel equivalents like `printk` instead of `printf`.
- **Kernel Tainting**: Loading proprietary or out-of-tree modules sets a "taint" flag (e.g., 'P' for proprietary), which may invalidate bug reports to the upstream kernel community.
- **Symbol Resolution**: The `Module.symvers` file generated during the kernel build process lists all exported symbols and their CRCs, which is essential for building out-of-tree modules.
